Pick a protocol by hand

If you already know your unit's protocol, choose it here and skip learning entirely.

Minimum off time protects the compressor: after the unit switches off, a request to start it again waits out the remaining seconds instead of short-cycling it. Rated power is only used for the energy estimate — leave it at 0 if you do not know it.

Teach the bridge your remote

Start with Identify. One button press is usually enough: if the protocol is recognised, the bridge can then build every command by itself, including combinations you never demonstrated.

What the bridge is hearing

Use another remote

The bridge hears every remote in the room, not just the air conditioner's. Pick a button you never use on your TV handset — a colour key, teletext, a spare input — and make it control the air conditioner.

Do not use a button from the air conditioner's own remote — the bridge needs those to follow what the unit is doing, and it will tell you if you try.

Webhook

Plain http:// only — a second encrypted connection does not fit on this device. Point it at something on your own network.

Automations

Rules that run on this device, whether or not anything is watching. Each one says: if these things are true, then do these things.

Scenes

One-tap presets. A scene only changes what you put in it, so a "Quiet" scene can set just the fan speed and leave everything else alone. Scenes appear on the control page, in Telegram, and as a dropdown in Home Assistant.

Other devices

Things this bridge reaches over the network rather than by infrared: other SLWF units, WLED and ESPHome devices, a computer to wake, a sensor to read. Once added they appear on the control page and can be used in automations.

Access control

Device

Usage

Energy is running time multiplied by the rated power you entered — good enough to spot trends, but it is an estimate, not a meter.

Pin assignment

Defaults follow the SLWF-12 r1.0 schematic: the receiver module (J2) sits on GPIO4 and the emitter driver (Q3) on GPIO16. Change these only if your board differs.

Language

English is built into the device and always available. Other languages are files that can be added — once added, a language stays on the device and works with no internet at all.

Add a language

The device never contacts anything on its own. If you ask, this browser — not the device — will fetch the list of available languages from the project's page on GitHub, and then the one you pick. The pack is sent to the device over your own network and kept there.

Install from a file

For a browser that cannot reach GitHub either — on the device's own setup network, for instance. Download the pack on any machine and choose the file here. Nothing leaves your network.

Units and formats

How this device writes things down, and which unit it speaks to the air conditioner in. The unit is not only a display choice: it goes out in the infrared frame, so the unit's own display follows it.

Device time

Schedules, timers and time-based automations all read this clock. The board has no battery, so it starts each time from nothing and asks a time server on the internet.

Timezone

Sets what the device calls 8 o'clock, including when summer time starts and ends. Worth getting right even without a time server.

Location

Only used to work out sunrise and sunset, on the device and with no network at all. Rules can then say "half an hour before sunset", which keeps meaning the same thing all year — a fixed hour does not. Leave it blank and the sun is simply not mentioned.

Time server

Set the time by hand

For a device with no way out to the internet. The time you set holds until the device restarts — there is no battery to keep it — and a time server, if one ever answers, takes over.
